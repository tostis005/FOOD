# Quinnoa article topic inventory

This folder is the canonical inventory of approved Quinnoa article topics.

The inventory is split into numbered ranges so it can grow without mixing topic planning with the Spanish and English article files.

## Topic files

- `TOPICS-001-635.md` — approved topics 1–635.
- `TOPICS-636-775.md` — approved topics 636–775.
- `TOPICS-776-915.md` — approved topics 776–915.

Future approved batches must be added to this folder as a new non-overlapping numbered range.

## Mandatory use

Before drafting, rewriting or validating a numbered article:

1. Read `AGENTS.md`.
2. Read this file and the topic file containing the target `article_number`.
3. Use the exact approved topic/search intent for that number; do not invent, merge, replace, reorder or skip topics.
4. When checking whether a topic already exists, or when proposing future topics, search **all topic files in this folder**, not only the current range. This folder-wide check is required to reduce duplication and search-intent cannibalization.
5. Spanish and English versions share the same `article_number` and `translation_group`, while each language is written natively for its market.

The article body files remain in their existing locations. Maintaining this inventory must not move or reorganize the Spanish or English article content.
